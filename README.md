# 📚 StudyFlow

O **StudyFlow** é uma aplicação web desktop criada para ajudar estudantes a organizar sua rotina acadêmica de forma simples e prática.

O sistema permite gerenciar **matérias e trabalhos**, reunindo as principais informações acadêmicas em um único lugar.

## 🚀 Funcionalidades

* 🔐 **Login** — acesso do usuário ao sistema.
* 📝 **Cadastro** — criação de uma nova conta.
* 🏠 **Dashboard** — visão geral das matérias e trabalhos.
* 📚 **Matérias** — cadastro e gerenciamento das disciplinas.
* 📋 **Trabalhos** — organização de trabalhos, prazos e status.

## 🖥️ Fluxo principal


Login / Cadastro
       ↓
   Dashboard
    ↙     ↘
Matérias  Trabalhos


## 🎯 Objetivo

O objetivo do StudyFlow é facilitar a organização acadêmica, permitindo que o estudante acompanhe suas **matérias, trabalhos e prazos** através de uma interface simples e intuitiva.
